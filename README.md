# Agenda

Agenda is a simple iOS task management app built with SwiftUI and SwiftData.

## Features
- Create, edit and complete tasks
- Today & Upcoming task views
- Statistics view with Charts
- Persistent storage using SwiftData
- Clean SwiftUI navigation

## Tech Stack
- SwiftUI
- SwiftData
- Charts framework
- Notifications framework

## Notes
Developed as part of a university iOS development assignment.
